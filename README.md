This repository contains code for brain-age prediction using 3D MRI data from the OpenBHB website. This was done as part of a project for EECS 545. The goal is to use two separate methods for this problem. The first one is inspired by the success of Gaussian splatting and aims to use Gaussian Mixture Models to store spatial correlation. The second method uses Functional Data Analysis to capture the underlying smooth surface. Both techniques are augmented with a deep neural network for prediction.
